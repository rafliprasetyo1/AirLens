Build guides

Step-by-step guides for wiring, testing and assembling the AirLens nodes.

  • Running at this booth Beta version

    ESP32 DevKit V1 with four MQ gas sensors (MQ-2, MQ-3, MQ-7, MQ-135), each through a voltage divider, sending readings over HTTPS to a small AI model explained with SHAP.
  • Full version · concept design Full version (concept)

    Raspberry Pi 5 with AI HAT+, Camera Module 3 Wide, Sensirion SEN66 and Alphasense CO-B4, in a 3D-printed case.

Beta tools (operator)

  • Chrome or Edge · USB Flash tool

    Install the AirLens Beta firmware (4 MQ gas sensors) from the browser and save WiFi, the AirLens address and the node token on the device.
  • Chrome or Edge · USB Calibration recorder

    Record labelled readings (clean air, incense smoke, hand sanitizer) from the device and download them as CSV.
