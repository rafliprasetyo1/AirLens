Build guides

How to wire, test and assemble AirLens, step by step.

  • AirLens Beta

    ESP32 DevKit V1 with four MQ gas sensors (MQ-2, MQ-3, MQ-7, MQ-135), each through a voltage divider, sending readings over HTTPS to a small AI model explained with SHAP.

    The box running at this booth. Guide in Indonesian.
  • Full version (concept)

    Raspberry Pi 5 with AI HAT+, Camera Module 3 Wide, Sensirion SEN66 and Alphasense CO-B4, in a 3D-printed case.

    A design study. It has not been built.

Operator tools

These open only on the booth computer.

  • Flash tool

    Install the AirLens Beta firmware from the browser and save Wi-Fi, the AirLens address and the node token on the device.

    Needs Chrome or Edge and a USB data cable.
  • Calibration recorder

    Record labelled readings (clean air, incense smoke, hand sanitizer) from the device and download them as CSV.

    Needs Chrome or Edge and a USB data cable.
