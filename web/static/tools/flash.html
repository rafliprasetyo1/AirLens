Flash AirLens Beta

Install the firmware on the ESP32 from this browser, then save the WiFi network, the AirLens address and the node token on the device. Nothing needs to be installed on this computer.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer, through http://localhost:8080 or an https:// address.

1. Choose the firmware

  • Loading firmware list…

2. Connect and flash

Connect the board with a USB data cable. If no port appears, the computer may need the CP210x or CH340 USB driver (admin rights); flash from another computer instead, because the device keeps the same AirLens address.

No device connected.

3. Set WiFi and server

These settings go straight to the device over USB and are stored in its memory (NVS). The password is never saved in this browser and never sent to the AirLens server.

The ngrok address, for example https://name.ngrok-free.app/api/sensor/readings
