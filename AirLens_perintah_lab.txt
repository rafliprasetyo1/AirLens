CARA PAKAI
- Salin SATU BLOK sekali jalan, tunggu selesai, baru lanjut ke blok berikutnya.
- Baris yang diawali # adalah penjelasan; kalau ikut tersalin, terminal mengabaikannya.
- Ganti semua <...> dengan nilai milikmu sendiri.
- Menempel di terminal Ubuntu: klik kanan, atau Ctrl+Shift+V.
- Tidak perlu hak admin Windows. Semua dipasang di WSL (folder pengguna).
- Jangan tutup terminal saat perintah masih berjalan.

BAWA DARI RUMAH (password manager, JANGAN di file teks biasa)
- IQAIR_API_KEY, KAGGLE_USERNAME, KAGGLE_KEY
- VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT (salin dari .env laptop agar notifikasi HP tetap jalan)
- SENSOR_TOKEN, NODE_TOKEN (dari .env laptop; HARUS sama dengan token yang disimpan di ESP32)
- Authtoken ngrok (dashboard.ngrok.com -> Your Authtoken)
- Alat Beta: ESP32 DevKit, 4 modul MQ (MQ-2, MQ-3, MQ-7, MQ-135), 4x resistor 10k + 4x 20k,
  breadboard, kabel jumper, adaptor 5 V 2 A, kabel USB data. Dupa + hand sanitizer untuk uji.


---------------------------------------------------------------------
LANGKAH 1 - Persiapan: buka Ubuntu, identitas git, ambil proyek, .env
---------------------------------------------------------------------
# Di PowerShell Windows:
wsl -l -v
wsl -d Ubuntu-24.04

# Di terminal Ubuntu:
for t in make git curl openssl python3; do command -v $t >/dev/null && echo "ada: $t" || echo "TIDAK ADA: $t"; done
docker compose version

git config --global user.name "rafliprasetyo1"
git config --global user.email "rafliprstyo5@gmail.com"
cd ~
[ -d AirLens ] && (cd AirLens && git pull) || git clone https://github.com/rafliprasetyo1/AirLens.git
cd ~/AirLens
git log --oneline -3

cp -n .env.example .env
sed -i "s|^POSTGRES_PASSWORD=.*|POSTGRES_PASSWORD=$(openssl rand -hex 24)|" .env
nano .env
#   Isi (nilai dari password manager):
#     IQAIR_API_KEY=...            KAGGLE_USERNAME=...        KAGGLE_KEY=...
#     SENSOR_TOKEN=...             NODE_TOKEN=...
#     VAPID_PUBLIC_KEY=...         VAPID_PRIVATE_KEY=...      VAPID_SUBJECT=...
#   Simpan: Ctrl+O lalu Enter. Keluar: Ctrl+X.
# Cek nama variabel yang terisi (nilai tidak ditampilkan):
grep -E '^[A-Z_]+=.+' .env | cut -d= -f1

# ngrok (sekali per komputer, tanpa sudo, ±10 MB):
mkdir -p ~/.local/bin
curl -sSL https://bin.equinox.io/c/bNyj1mQVY4c/ngrok-v3-stable-linux-amd64.tgz | tar -xz -C ~/.local/bin ngrok
export PATH="$HOME/.local/bin:$PATH"
ngrok config add-authtoken <AUTHTOKEN_NGROK>


---------------------------------------------------------------------
LANGKAH 2 - Cek kesiapan
---------------------------------------------------------------------
make doctor
# Setiap [MASALAH] disertai perintah perbaikannya. Ulangi make doctor sampai "HASIL: siap".
# Bila SENSOR_TOKEN/NODE_TOKEN belum ada sama sekali (ESP32 belum pernah di-flash): make tokens


---------------------------------------------------------------------
LANGKAH 3 - Nyalakan AirLens untuk pameran
---------------------------------------------------------------------
make expo-setup PROFILE=lab
# Mengambil model final dari Kaggle, menyalakan layanan, membuka ngrok, membuat QR.
# Catat dari keluarannya:
#   - Website publik: https://<alamat-sesi>.ngrok-free.app/
#   - URL sensor ESP32: https://<alamat-sesi>.ngrok-free.app/api/sensor/readings
# Alamat ngrok free berganti setiap sesi; kalau ngrok di-restart, jalankan: make expo-public
# lalu perbarui URL ESP32 (LANGKAH 5, bagian Set WiFi saja).
# Layar booth: buka http://localhost:8080 di Chrome komputer ini (tidak memakai kuota ngrok).


---------------------------------------------------------------------
LANGKAH 3b (opsional) - Gladi tanpa alat dengan Wokwi, kapan saja
---------------------------------------------------------------------
# Memastikan alur alat -> ngrok -> AirLens -> HP berjalan sebelum menyentuh hardware.
make gladi
# Ikuti petunjuk di layar (Wokwi di Chrome, tempel perintah SET, pantau halaman Beta dari HP).
# Selesai gladi (WAJIB, menutup jalur HTTP dan mengganti token):
make gladi-stop
# Token baru inilah yang disimpan ke ESP32 asli di LANGKAH 5.


---------------------------------------------------------------------
LANGKAH 4 - Rakit AirLens Beta dan uji tiap sensor
---------------------------------------------------------------------
# Buka panduan di Chrome komputer ini:
#   http://localhost:8080/modules/merakit-node-lite.html
# Ikuti langkah 1-3 (ESP32 hidup, pasang empat MQ, uji tiap sensor).
# Keselamatan: hanya dupa dan hand sanitizer, ruangan berventilasi. JANGAN pernah membuat gas CO.


---------------------------------------------------------------------
LANGKAH 5 - Flash ESP32 lewat Chrome dan simpan WiFi + URL ngrok + token
---------------------------------------------------------------------
# Chrome komputer ini (halaman alat hanya bisa dibuka dari komputer ini):
#   http://localhost:8080/tools/flash.html
# 1. Pilih "AirLens Beta: 4 MQ gas sensors" -> Connect a device -> pilih port -> Flash firmware.
# 2. Set WiFi and server:
#      WiFi name/password : WiFi 2,4 GHz di lab/booth
#      Server URL         : https://<alamat-sesi>.ngrok-free.app/api/sensor/readings
#      Node token         : nilai SENSOR_TOKEN (lihat di terminal: grep ^SENSOR_TOKEN= .env)
#      Seconds between readings: 10 saat pameran (hemat kuota ngrok gratis), 2 saat kalibrasi
#    -> Save to device. Log harus menunjukkan "wifi","status":"connected".
# ESP32 tidak terdeteksi? Lihat bagian "KALAU ESP32 TIDAK TERDETEKSI" di bawah.


---------------------------------------------------------------------
LANGKAH 6 - Pemanasan sensor (+-30 menit)
---------------------------------------------------------------------
# Biarkan alat menyala di udara bersih. Pantau di http://localhost:8080/beta.html:
# status Warming up -> Normal (baseline udara bersih dipelajari otomatis).


---------------------------------------------------------------------
LANGKAH 7 - Rekam kalibrasi
---------------------------------------------------------------------
# Hentikan dulu tab flash.html (port USB hanya bisa dipakai satu halaman), lalu buka:
#   http://localhost:8080/tools/recorder.html  -> Connect a device
# Rekam +-10 menit per label: Clean air -> Incense smoke (dupa +-50 cm) -> Clean air (buka jendela)
#   -> Hand sanitizer (tisu basah dekat sensor) -> Smoke + sanitizer.
# Download CSV (masuk ke folder Downloads Windows).


---------------------------------------------------------------------
LANGKAH 8 - Uji ujung ke ujung: sensor -> website -> SHAP -> notifikasi di HP
---------------------------------------------------------------------
# HP (data seluler, bukan WiFi lab): buka https://<alamat-sesi>.ngrok-free.app/beta.html
#   (atau pindai QR di docs/assets/qr_expo.png), lewati halaman peringatan ngrok sekali.
# 1. Tekan "Enable alerts", izinkan notifikasi.
# 2. Dekatkan dupa ke sensor: status Alert, kelas "Smoke", waterfall SHAP berubah.
# 3. Notifikasi masuk ke HP (juga saat browser ditutup di Android; iPhone lewat Home Screen).
# 4. Jauhkan dupa: "Back to normal".
# Cek dari terminal (kiriman tanpa token harus ditolak 401, alat operator harus 403 lewat ngrok):
make doctor


---------------------------------------------------------------------
LANGKAH 9 - Unggah CSV kalibrasi ke Google Drive
---------------------------------------------------------------------
# Di Chrome: drive.google.com -> folder tim -> unggah airlens_beta_recording_*.csv dari Downloads.
# (Di laptop nanti: make import-beta-recordings CSV=<berkas.csv>)
